Press ⌘/ in Writing Desk to open this list inside the app, with a search box to find a shortcut quickly. You'll also find it under **Help → Keyboard Shortcuts** in the menu bar.

## File

| Action | Shortcut |
|---|---|
| New document | ⌘N |
| Open | ⌘O |
| Save | ⌘S |
| Save as | ⇧⌘S |
| Close document | ⌘W |
| Quit Writing Desk | ⌘Q |

## Editing

| Action | Shortcut |
|---|---|
| Undo | ⌘Z |
| Redo | ⇧⌘Z or ⌘Y |
| Find and replace | ⌘F |
| Paste and match style | ⇧⌘V |
| Line break within a paragraph | ⇧↩ |

## Formatting

| Action | Shortcut |
|---|---|
| Bold | ⌘B |
| Italic | ⌘I |
| Underline | ⌘U |
| Strikethrough | ⇧⌘X |
| Add or edit a link | ⌘K |
| Clear formatting | ⌘\ |
| Body text | ⌥⌘0 |
| Heading 1 | ⌥⌘1 |
| Heading 2 (chapter) | ⌥⌘2 |
| Heading 3 (scene) | ⌥⌘3 |
| Bulleted list | ⇧⌘8 |
| Numbered list | ⇧⌘7 |
| Quote | ⇧⌘B |
| Align left | ⇧⌘L |
| Centre | ⇧⌘E |
| Align right | ⇧⌘R |
| Justify | ⇧⌘J |

## Comments

| Action | Shortcut |
|---|---|
| New comment on the selection | ⌥⌘M |
| Save the comment | ⌘↩ |
| Cancel the comment | Esc |

## Tabs and view

| Action | Shortcut |
|---|---|
| Go to tab 1 to 8 | ⌘1 to ⌘8 |
| Go to the last tab | ⌘9 |
| Next tab | ⇧⌘] |
| Previous tab | ⇧⌘[ |
| Show or hide the tab bar | ⇧⌘T |
| Show or hide the sidebar | ⌃⌘S |
| Enter or leave Focus Mode | ⇧⌘F |
| Leave Focus Mode | Esc |
| Full screen | ⌃⌘F |

## Panels

| Action | Shortcut |
|---|---|
| Research Assistant | ⇧⌘K |
| Send a chat message | ⌘↩ |
| Keyboard shortcuts | ⌘/ |

## Story Plotter

| Action | Shortcut |
|---|---|
| Body text | ⌥⌘0 |
| Chapter | ⌥⌘2 |
| Scene | ⌥⌘3 |
| Heading 4 | ⌥⌘4 |

## Reading the symbols

⌘ is Command, ⇧ is Shift, ⌥ is Option, ⌃ is Control and ↩ is Return.
