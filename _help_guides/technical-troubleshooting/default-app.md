Your Mac opens each kind of file in one default app. If double-clicking a Word file opens Pages or Word, you can switch it to Writing Desk in a few clicks.

## Set Writing Desk as the default

1. In Finder, select any .docx file.
2. Press ⌘I, or choose **File → Get Info**.
3. Under **Open with**, choose **Writing Desk**.
4. Click **Change All…**, then **Continue**.

Every .docx file now opens in Writing Desk. Repeat the steps with a .md file to do the same for markdown.

## Opening a file once without changing the default

Control-click the file in Finder, choose **Open With**, then **Writing Desk**.

## Writing Desk documents

Writing Desk documents (.wddoc) always open in Writing Desk, and show as "Writing Desk Document" in Finder's Kind column.
