FAQ

Writing app FAQs.

Can I open existing Word files?

Yes. Open any .docx from the home screen or Finder and it opens as it is. Edit it and it saves back to .docx automatically. Tracked changes and complex formatting may not survive, so keep a copy of files that rely on them.

Do markdown documents work in other apps?

Yes. Documents created with Writing Desk are standard .md files, so any markdown editor opens them.

Does the AI write for me?

No. The editorial review reads your piece through four lenses and suggests changes with reasons. You accept or reject each one. It never writes prose on your behalf.

What is the difference between a document and a project?

A document is a single file, .md or .docx, with a simple sidebar made for shorter writing. A project is the full novel setup as a .wddoc file, with chapters, Story Plotter, chapter variants, Resource Hub, dedicated reference folder, version history, comments, and publishing export.

Can I turn a document into a novel project?

Yes. Choose Set up project and Writing Desk makes a .wddoc copy. Your original file stays as it was.

Does Writing Desk work offline?

Yes. Writing, editing and the spelling and grammar checker work without a connection. AI editorial review needs one.

What does Writing Desk cost?

The core writing environment is free and stays free. Every new install includes 30 days of the full program, and when those end the Pro and Premium features pause while you keep writing. Paid plans start from £8 per month when you pay annually. See pricing.

Is there a Windows version?

Writing Desk runs on Mac only today. A Windows app is on the roadmap but there is no launch date yet.
